# tradelogie-media

Tradelogie'nin X gonderileri icin taslak gorselleri.

Bu repo **public**, cunku tek isi bu: GitHub'in Camo proxy'si bir issue govdesine
gomulu gorseli sunucu tarafinda, okuyanin oturumu olmadan cekiyor — private bir
reponun ham adresi ona 404 donuyor ve onay kuyrugundaki gorsel telefonda hic
gorunmuyor.

Buradaki dosyalar zaten X'te herkese acik paylasilmak uzere uretiliyor, yani
public olmalari bir sey eksiltmiyor. Stratejinin, yazim kurallarinin ve
yayin gecmisinin tamami private `trading_journal_marketing` reposunda kaliyor.

Dosyalar `trading_journal_marketing`'in `review/openIssue.ts` adimi
tarafindan buraya push ediliyor; elle bir sey eklenmiyor.
